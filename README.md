# Backend Training – Node.js & NestJS

Duration: 2 Weeks  
Goal: Build a structured NestJS API with validation and testing.

## How to Work

1. Create a branch training-name.
2. For every task:
    - Create a branch for each day name-task-#.
    - Complete the coding task.
    - Answer the understanding questions.
    - Open a Pull Request from name-task-# to training-name.
    - Be ready to explain your code.
